Python Operators Notes
1. Arithmetic Operators

Definition: Arithmetic operators are used to perform mathematical operations.

Operator	Meaning	Example	Output
+	Addition	10 + 5	15
-	Subtraction	10 - 5	5
*	Multiplication	10 * 5	50
/	Division	10 / 5	2.0
//	Floor Division	10 // 3	3
%	Modulus (Remainder)	10 % 3	1
**	Exponent	2 ** 3	8
Example
a = 10
b = 3

print(a + b)    # 13
print(a - b)    # 7
print(a * b)    # 30
print(a / b)    # 3.3333333333333335
print(a // b)   # 3
print(a % b)    # 1
print(a ** b)   # 1000
2. Assignment Operators

Definition: Assignment operators assign values to variables.

Operator	Example	Equivalent To
=	a = 10	Assign value
+=	a += 5	a = a + 5
-=	a -= 5	a = a - 5
*=	a *= 5	a = a * 5
/=	a /= 5	a = a / 5
//=	a //= 5	a = a // 5
%=	a %= 5	a = a % 5
**=	a **= 2	a = a ** 2
Example
a = 10

a += 5
print(a)      # 15

a -= 2
print(a)      # 13

a *= 2
print(a)      # 26

a /= 2
print(a)      # 13.0

a //= 2
print(a)      # 6.0

a %= 4
print(a)      # 2.0

a **= 3
print(a)      # 8.0
3. Comparison (Relational) Operators

Definition: Comparison operators compare two values and return True or False.

Operator	Meaning	Example	Output
==	Equal	10 == 10	True
!=	Not Equal	10 != 5	True
>	Greater Than	10 > 5	True
<	Less Than	10 < 5	False
>=	Greater Than or Equal	10 >= 10	True
<=	Less Than or Equal	5 <= 10	True
Example
a = 10
b = 20

print(a == b)    # False
print(a != b)    # True
print(a > b)     # False
print(a < b)     # True
print(a >= 10)   # True
print(b <= 20)   # True
4. Logical Operators

Definition: Logical operators combine multiple conditions.

Operator	Meaning	Example
and	Both conditions must be True	a > 5 and b > 10
or	At least one condition must be True	a > 5 or b < 10
not	Reverses the result	not(a > 5)
Example
a = 10
b = 20

print(a > 5 and b > 10)    # True
print(a > 5 and b < 10)    # False

print(a > 5 or b < 10)     # True
print(a < 5 or b < 10)     # False

print(not(a > 5))          # False
print(not(a < 5))          # True
5. Identity Operators

Definition: Identity operators check whether two variables refer to the same object in memory.

Operator	Meaning
is	Same object
is not	Different objects
Example
a = [1, 2]
b = a
c = [1, 2]

print(a is b)        # True
print(a is c)        # False

print(a == c)        # True

print(a is not c)    # True
Difference
a == c

Checks values.

a is c

Checks memory address (object identity).

6. Membership Operators

Definition: Membership operators check whether an element exists in a sequence.

Operator	Meaning
in	Element exists
not in	Element does not exist
Example with List
fruits = ["Apple", "Mango", "Banana"]

print("Apple" in fruits)       # True
print("Orange" in fruits)      # False

print("Orange" not in fruits)  # True
Example with String
text = "Python"

print("P" in text)      # True
print("Z" in text)      # False
Example with Dictionary
student = {
    "name": "Sandip",
    "age": 22
}

print("name" in student)     # True
print("city" in student)     # False

Note: In dictionaries, in checks keys, not values.

7. Bitwise Operators

Definition: Bitwise operators work on the binary representation of integers.

Operator	Meaning	Example
&	AND	5 & 3
`	`	OR
^	XOR	5 ^ 3
~	NOT	~5
<<	Left Shift	5 << 1
>>	Right Shift	5 >> 1
Example
a = 5      # 101
b = 3      # 011

print(a & b)     # 1
print(a | b)     # 7
print(a ^ b)     # 6
print(~a)        # -6
print(a << 1)    # 10
print(a >> 1)    # 2
Binary Explanation
a = 5 = 101
b = 3 = 011
