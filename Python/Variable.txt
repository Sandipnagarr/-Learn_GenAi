4. How are variables stored conceptually in memory?

Unlike languages such as C, a Python variable does not store the value itself. Instead, it stores a reference to an object.

Step 1: Create an object
x = 10

Conceptually, Python does this:

Memory
+----------------+
|  Integer 10    |
+----------------+

Then it creates a variable that points to that object

Variable
   x
   │
   ▼
+----------------+
|  Integer 10    |
+----------------+

So:

x is the variable (reference)
10 is the object

++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
Step 2: Another variable points to the same object
x = 10
y = x

Memory:

      x
      │
      ▼
+----------------+
|  Integer 10    |
+----------------+
      ▲
      │
      y

Both x and y refer to the same object.

Check it:

x = 10
y = x

print(id(x))
print(id(y))

Output (example):

1402838472
1402838472
